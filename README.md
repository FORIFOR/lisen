# ListenFlow

**英語が聞こえる毎日へ。** 毎日30分から、好きなだけ学べる適応型の英語リスニングトレーニング。

MacBook Pro で動かすローカルファーストの Web アプリです。Mac・Windows・iPhone のブラウザから、同じ学習データ（履歴・復習予定・弱点・進捗）にアクセスできます。

## 起動

```bash
./start.sh
```

初回は Python 環境・npm パッケージ・Web アプリのビルドを自動で行います（教材音声は `backend/media/` に生成済み）。起動すると、他の端末から開くアドレスが表示されます。

| 端末 | 開くアドレス |
| --- | --- |
| この Mac | http://localhost:3210 |
| 同じ Wi-Fi の Windows / iPhone | http://<Mac の IP>:3210 （設定画面にも表示） |
| 外出先（Tailscale） | http://<Mac の Tailscale IP>:3210 |

- iPhone: Safari で開いて「共有 → ホーム画面に追加」でアプリのように使えます。
- Mac がスリープ中は他の端末から接続できません。
- **端末の登録が必要です。** 各端末（この Mac のブラウザも含む）で初回だけ、`./start.sh` が表示するアクセスコード（12桁）を入力します。登録した端末はブラウザの Cookie（HttpOnly、約1年）で識別し、Mac にはその値のハッシュだけを保存します。未登録の端末からは学習データ・音声・設定・エクスポートのどれも読めません。コードの入力に5回失敗すると10分間は登録できません。端末の一覧・登録の解除・コードの変更（ほかの端末はすべて登録が外れます）は「設定 → 端末とアクセス」で行えます。コードは `data/secrets/access.code`（権限 600）にあります。
- Web は既定で全インターフェースで待ち受けます（同じ Wi-Fi の iPhone から使うため）。HTTP なので、同じネットワーク上で通信を盗み見られる可能性は残ります。外出先や共用の Wi-Fi では Tailscale 経由で使い、Tailscale だけに絞るなら `LISTENFLOW_HOST=<Tailscale IP> ./start.sh`、この Mac だけなら `LISTENFLOW_HOST=127.0.0.1 ./start.sh`。認証をやめる場合は `LISTENFLOW_AUTH=off`（おすすめしません）。
- シャドーイングの録音はブラウザの仕様で HTTPS か localhost が必要です。iPhone で使う場合は `tailscale serve --bg 3210` で HTTPS 化してください（録音以外の機能は HTTP でも動きます）。
- ポート: Web 3210 / API 8765（`LISTENFLOW_WEB_PORT` / `LISTENFLOW_API_PORT` で変更可。API は 127.0.0.1 のみで待ち受け、Web 経由で `/api/*` として中継）。

## 何ができるか

- **最初に4つの能力を測る（リスニング診断・約20〜25分）**: 音声識別10問（弱形・連結・短縮形・語尾・数字の聞き分け）→ TOEIC 語彙20問（音・文脈で認識）→ 構文理解10問（1文を聞き、否定・時制・条件・受け身などで決まる意味を答える）→ 初見の会話5本（10問＋書き取り）。診断中は答えを見せません。結果は「Listening Profile」として保存し、毎日の回答で更新します（直近ほど重く数えた推定値と95%区間の目安。8問未満は暫定）。
- **会話 → 1文 → 応用（標準のトレーニング）**: 初見の会話を文字なしで聞いて要点に答え、各行を書き取って聞き取れなかった1文を見つけます。その1文は「英文を見れば意味が分かるか」を先に答えてから、日本語訳・場面・重要表現・構文・聞き取れなかった音の解説を見ます。最後に、同じ表現を使った**別の場面・別の話者の文**を初めて聞いて答えます（応用）。30分なら「語彙・表現の復習 5分 ＋ この流れ 25分」です。
  - 原因の推定: 読めば分かる → 音声知覚、知らない単語 → 語彙、単語は分かるが意味がつかめない／訳と違った → 構文、全行聞き取れたのに要点を誤答 → 統合理解。1回では断定せず、8件以上たまってから「分析」に傾向を表示します。
  - 初見の会話の正答率、応用文の正答率、解説後の自己申告は別々に記録し、解説を見た後の結果を初見理解率に混ぜません。
  - 内蔵教材257行の日本語訳と応用文247問は ListenFlow 用に書いたもの（`backend/content/notes/`、CC0）。作成者とは別のレビューで訳・正解・選択肢を点検済み。Gemini の教材は、訳と応用文を別の呼び出しで検証し、通ったものだけを付けます（検証できないときは付けません）。
- **弱い能力に時間を寄せる**: 30分以上のプランでは、目標（音声識別65%、ほか70%）から最も遠い能力の訓練に約15%の時間を移します。初見リスニングは常に学習時間の25%以上を残します。延長（「あと30分」）は復習を繰り返さず、弱い能力の訓練から始まります。
- **移動リスニング（文字入力なし）**: ホームで「移動リスニング」を選ぶと、5・10・15・30分で同じ「会話 → 1文 → 応用」をタップだけで進めます。会話を聞いて要点に答え、各行を1文ずつ聞いて「意味まで分かった／音は聞こえたが意味が分からない／音を聞き取れなかった」をタップし、意味まで分からなかった最初の1文の訳・場面・重要表現を確かめ、同じ表現の別の文を聞いて答えます。スマホでは答えのボタンが画面の下に出ます。「音は聞こえたが意味が分からない」を選んだ文は訳・重要表現・構文を、「音を聞き取れなかった」を選んだ文は英文を見ながらのゆっくり再生を、先に示します。音声はページ全体で1つの再生要素を使い回すため、iPhone でも最初に1回再生ボタンを押せば、その後の文は自動で流れる作りです（iPhone 実機では未確認）。タップは自己申告なので、どれを選んだかも含めて書き取りの正確さとは別に記録し、能力の推定やレベルは動かしません。聞き取れなかった文は、次の通常の学習で書き取りの復習に出ます。「分析」で、通常と移動の初見会話理解率を並べて表示します（聞いた会話が違うので、差は目安です）。
- **14日ごとの確認テスト**: Day 1・15・29・43・57 に、一度も聞いていない同じ構成（レベル1〜5 × 各2問）の音声でテスト。練習した文章の暗記を伸びと見なさないためです。
  - どの音声セット（A〜E）を何回目に使うかは**利用者ごとにランダム**（初回に決めて保存。受験済みの回は固定）。ある回だけ易しくても、それが特定の時期の「伸び」に見えないようにするためです。
  - 5セットの客観指標（語数・話す速さ・1文の長さ・3音節以上の語の割合・要点/推論の設問数）を固定の基準（平均との差 15% / 10% / 15% / 4pt / 1問以内）で比較し、分析画面に表示。テストでも同じ基準を確認します。現状は全項目が基準内（最大の差：語数 13%、速さ 5%）。これは難しさが等しいことの証明ではありません（多数の利用者の回答データが必要）。
- **成果の指標**: 初見会話理解率（最重要）・初回再生での理解率（最初から1回だけ聞いて答えたもの）・音声識別正答率・音声語彙認識率・7日/30日継続率を、直近14日と前の14日で比較。理解問題の選択肢は出題ごとに並べ替えます（同梱教材は正解が2番目に偏っていたため、位置で当てられないように）。
- **今日の成長**: 以前間違えた単語を初めて聞く会話の中で聞き取れたとき、以前間違えた文の構造を正しく理解できたときに記録して表示します。
- **興味に合わせた教材**: AI・テクノロジー / ビジネス / 自然な会話 / 科学・教養 / 旅行 / 日常 から選ぶと、初見リスニングとホームの「おすすめ」で優先。おすすめから選んだ音声で学習を始められます。
- **学習時間を選ぶだけ**: 15 / 30 / 60 / 90 / 120 分、または 5〜300 分の任意指定。途中で延長・一時停止・別端末で再開ができます。
- **長い日は内容が変わる**: 時間が増えると同じ問題を水増しせず、新しい音声・複数話者の会話・長めの講義・語彙・総合復習のブロックが加わります。60分以上では休憩（3〜10分、間隔も設定可）を自動で挟みます。
- **初見リスニング → 書き取り**: まず文字なしで聞いて内容理解問題、その後スクリプトを確認し、1文ずつディクテーション。2文続けて 90% 以上聞き取れたら新しい音声へ進みます。
- **聞き取りミスの分析**: 語単位で正誤を判定し、ミスを「弱形（機能語）・短縮形・音の連結・数字・語尾・語彙」に分類。数字は算用数字でも英単語でも、短縮形は展開形でも正解扱い。綴りの軽いミスは「聞き取れている」と判定します。
- **弱点別の集中訓練**: 習熟度の低いスキルを狙ってディクテーションと「聞き分け」（a / the、I'll / I'd、-s の有無など）を出題。
- **FSRS による自動復習**: 聞き取れなかった文・語彙をカード化し、FSRS（py-fsrs）で次の復習日を決定。
- **能力別の解放**: レベルは日数ではなく正答率で上下します（書き取り 85%・理解 75% で次レベル解放）。
- **60日カリキュラム**: 10日ごとに重点テーマが変わり、61日目以降も弱点ベースで継続できます。
- **教材の追加**: 英文スクリプトを入力すると Mac の音声合成で音声を作成。スクリプトがそのまま採点の正解になります。
- **TOEIC 語彙エンジン**: 単語ごとに「文字で理解」「音声で認識」「会話（文の中）で理解」の3つの習熟度を別々に記録。3つすべてが 80% 以上になるまで「習得済み」にしません。
  - 語彙診断（約40問）: 答えに合わせて難易度が上下（2問連続正解で上・1問ミスで下）。音声で分からなかった単語は数問後に文字でも確認し、「意味を知らない」のか「音で認識できない」のかを分けます。自信度（勘で答えた・分からない）と回答時間も記録。
  - 単語の状態: 意味を覚えていない / 文字では分かるが音で認識できない / 単語単体では聞けるが文の中で聞き取れない / 学習中 / 習得済み / 一度覚えたが忘れた。
  - 復習: 間違えた・勘で答えた単語は、その能力ごとに FSRS カードになり、毎日の学習（30〜120分のコースの「TOEIC 語彙」ブロックと「復習」）に自動で組み込まれます。
  - 苦手語彙の音声教材: 弱い単語を含む会話を作り、Mac の音声合成で音声化。次の「初見リスニング」で優先出題され、書き取りで単語を聞き取れたかが「会話で理解」に反映されます。品質チェック（指定語がすべて含まれる・英語のみ・正解が1つだけの問題・音声の長さと発話速度）に通らない教材は使いません。同じ単語の組み合わせはキャッシュして再生成しません。
  - 分析画面の「語彙 Vocabulary」タブで、能力別の習熟度・重点単語・難易度別の状況を確認できます。
- ダークモード、キーボード操作（Space 再生 / R 最初から / S ゆっくり / 1–4 選択 / Enter 決定 / P 一時停止 / 入力中は Tab で再生）、学習データの JSON エクスポート。

## 教材と音声について

同梱の教材は 74 本（練習用 49 本: レベル A2〜C1、うち AI・ビジネス・自然な会話の 9 本を追加。テスト用 5 回分 × 5 本）と、構文理解の短文 40 問（`backend/content/sentences.json`、CC0、レベル1〜5 × 8問）。すべて ListenFlow 用に書き下ろしたもので、追加分は音声認識で台本どおりに読まれているかを確認済みです。音声は macOS の音声合成（`say`：米・英・豪・アイルランドの複数話者）で**スクリプトから生成**しているため、正解テキストと音声区間は構造上一致します。採点は Whisper などの自動文字起こしに依存しません。

合成音声は実際の会話より音の変化（脱落・連結）が少ないため、上級者には物足りない可能性があります。実音声の教材は、教材ページの「NotebookLM の音声を取り込む」から取り込めます（下記）。

## 学習データのバックアップと復元

- API の起動時と、その後24時間ごとに、学習データ（SQLite）を `data/backups/listenflow-YYYY-MM-DD.db` に保存します。使用中でも一貫した状態で複製し、壊れていないことを確かめてから置き換えます。最新14件を残します。「設定 → 端末とアクセス → 今すぐバックアップ」でも作れます。
- 復元は ListenFlow を止めてから: `cd backend && .venv/bin/python -m scripts.restore_backup`（一覧）→ `.venv/bin/python -m scripts.restore_backup <ファイル名>`。今のデータは `listenflow.db.before-restore-<日時>` として残すので、元に戻せます。
- バックアップは同じ Mac の中にあるだけなので、Mac の故障には備えられません。Time Machine などで `data/` も外部に保存してください。
- 学習データは Mac の1か所だけにあり、端末ごとの複製を同期する仕組みではないため、同期の競合は起きません。書き込みは1件ずつ順に行います。ただし、2台で同じセッションを同時に進める使い方は想定していません。

## 語彙データと Gemini

- 単語データ `backend/content/vocab/toeic_core.json`（198語、CC0）は ListenFlow 用に書き下ろしたもので、公式 TOEIC 教材や他の単語集からの転載はありません。`tier`（難易度1〜4）は作成者による独自の目安で、CEFR や TOEIC 公式の値ではありません。CEFR・TOEIC 関連度の欄は、ライセンスを確認できるデータを取り込むまで空欄です。読み込み時に重複・例文に単語が含まれるか・ライセンス表記などを検証し、不正なら起動しません。
- 単語の音声は `scripts/build_audio.py` で生成済みです（`backend/media/vocab/`）。
- Gemini で自然な会話文を作るには（任意。未設定ならローカル生成）: 設定画面の「Gemini」に API キーを貼り付けて保存（`data/secrets/gemini.key`、権限 600、画面・エクスポートには末尾4文字以外出ません）。環境変数 `GEMINI_API_KEY=... ./start.sh` でも可（こちらが優先）。モデルと「自動 / Gemini のみ / ローカルのみ」も設定画面で選べます。自動では Gemini が失敗・品質チェック不合格（1回再試行）のときローカル生成に切り替えます。送信するのは対象の単語とレベルだけです。Gemini の利用は Google の料金体系に従います。Gemini が作るのは会話文だけで、設問は採点できるようにローカルで機械的に作ります。
- 教材の音声は「Mac の音声合成」か「Gemini TTS」（`gemini-2.5-flash-preview-tts`、教材ごとに別の話者の組み合わせ、1行ずつ生成）を選べます。どちらも音声認識の照合に通ったものだけを使い、「自動」では Gemini TTS が使えないとき Mac の音声に切り替えます。
- TOEIC のスコア予測は行いません（実測データによる妥当性検証ができていないため）。

## 構成

| 領域 | 採用技術 |
| --- | --- |
| フロントエンド | Next.js 16 + TypeScript, Tailwind CSS v4 + shadcn/ui, Motion |
| API | FastAPI（全ての書き込みを API に集約し、1つのロックで直列化） |
| DB | SQLite（WAL）: `data/listenflow.db` |
| 復習 | FSRS（py-fsrs。ts-fsrs と同じアルゴリズムの Python 実装。スケジュールはサーバー側で一元管理） |
| 音声 | macOS `say` + FFmpeg |
| 端末間接続 | 同一 LAN / Tailscale |

```
backend/
  app/          API・採点(scoring)・学習プラン(planner)・出題エンジン(engine)・学習者モデル(progress)・FSRS(srs)
                語彙(vocab_data: 辞書と検証 / vocab: 診断・習熟度・復習 / lessons: 音声教材の生成と品質チェック)
  content/      教材スクリプト（JSON）、vocab/ 単語データ
  media/        生成済み音声 + manifest.json
  scripts/      build_audio.py（音声の再生成: --force）
  tests/        pytest
frontend/       Next.js アプリ
data/           学習データ（git 管理外）
```

## 開発

```bash
cd backend && .venv/bin/python -m pytest -q        # API・採点・プラン・学習フローのテスト
cd frontend && npx tsc --noEmit && npx eslint . && npm run build
```

Docker Compose（`docker compose up --build`）でも起動できますが、コンテナ内では音声合成ができないため教材の追加は使えません。将来、常時稼働の Mac mini やサーバーへ移す場合の構成です。


## 音声認識（faster-whisper）と NotebookLM の取り込み

- 導入: `./start.sh --setup-asr`（Python 3.10〜3.12 で `backend/.venv-asr` を作成。本体の Python 3.15 では依存がビルドできないため別環境）。モデルは初回に `backend/.models` へ自動ダウンロード（既定 `base.en` 約145MB、`LISTENFLOW_ASR_MODEL` で変更）。
- 音声教材の品質チェック: 合成した音声を文字起こしし、台本との単語誤り率 15% 以下・指定語が聞き取れる・認識の確信度（平均 0.80 以上、0.3 未満の語が 15% 以下）を確認。照合は1行ずつ行います（教材全体を一度に認識させると前後の音声に引きずられて誤認識が起きるため）。しきい値は同梱74本を同じ方法で測った実測（誤り率 中央値1.5%・最大12.9%、確信度 最低0.906、不合格0本）から決定。未導入時は「未実施」と表示し、合格扱いにはしません。
- NotebookLM の取り込み: 教材 → 「NotebookLM の音声を取り込む」。音声解説（m4a / wav / mp3 など、60分・300MB まで）を約90秒ずつの教材に分け、3〜12秒の書き取り行を作ります。台本を貼ると文字は台本、時刻だけ音声認識を使います（音声と25%以上食い違う台本は拒否）。台本なしでは確信度の低い部分を除外します。TOEIC 単語が出てくる教材には正解が1つだけの問題を作り、書き取りの結果が「会話で理解」に反映されます。問題のない教材は採点せず、レベルも変えません。話者の区別はしません。元のアップロードは処理後に削除します。
